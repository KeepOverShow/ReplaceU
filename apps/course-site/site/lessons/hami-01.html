从硬件到 Node 资源：这些名词各指什么？

PCIe 设备：显卡接在主机上的硬件。Linux 能在硬件总线上发现它，说明“机器看到了卡”，还不等于 CUDA 可用。

NVIDIA 驱动与设备文件：驱动让系统能操作显卡；/dev/nvidia0、/dev/nvidiactl 等设备文件是程序访问驱动的入口。驱动未正常加载时，能看到 PCIe 设备也可能无法使用 GPU。

NVML：NVIDIA Management Library，供用户态程序查询 GPU 型号、ID、健康等信息的库。nvidia-smi 使用这类管理接口；HAMi 的设备插件也借它枚举本机 GPU。

Device Plugin：运行在节点上的进程，把本机设备转换成 kubelet 能识别的设备 ID。此处的 VisitDevices() 正在枚举硬件，GetName() 读取型号；还没有把资源写进 Node。

注册与设备列表：插件先向 kubelet 注册资源名和自己的 socket；kubelet 再调用 ListAndWatch 接收设备 ID 与健康状态。后续 kubelet 才据此计算并上报 Node.status.capacity、allocatable。

记忆顺序：Linux 发现卡 → 驱动可访问 → NVML 可查询 → 插件枚举并上报 → kubelet 更新 Node 资源。
