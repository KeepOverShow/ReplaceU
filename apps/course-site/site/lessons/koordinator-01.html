逐步讲解

Koordinator 在 Kubernetes 上增加资源编排和混部能力。先记三个组件：koord-manager、koord-scheduler、koordlet。

按“谁决定、谁执行”读图

koord-scheduler 基于调度框架和插件做放置决策；koordlet 在节点侧采集指标并执行节点资源与 QoS 治理；koord-manager 运行控制器与 Webhook。组件主要通过 Kubernetes API 对象和配置协作。

request 和真实负载不同

两个节点声明的 request 相同，真实 CPU 使用量可能不同。负载感知调度利用采集指标辅助选择节点，但指标会延迟，仍要结合可分配资源、阈值和策略。
